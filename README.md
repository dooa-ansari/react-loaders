# ⚡ React Loaders

**16 loading animations. Pure CSS. Zero dependencies. Copy, paste, done.**

Every loader is a tiny React component plus one CSS file. No libraries, no config: copy the two files into your project and use it.

## ✨ Loaders

Bouncing Dots · DNA · Equalizer · Flip Cube · Glitch · Gradient Ring · Hourglass · Infinity Loop · Liquid Fill · Newton's Cradle · Orbit · Pacman · Paper Fold · Progress Stripes · Ripple · Wave Text

## 🚀 Run locally

```bash
npm install
npm run dev
```

Click any card to view it fullscreen (← → to browse, Esc to close), or hit **JSX** / **CSS** to copy the source.

## 📦 Use one in your app

1. Copy `src/loaders/Orbit.jsx` and `src/loaders/Orbit.css` into your project
2. `import Orbit from './Orbit'`
3. `<Orbit />`

## ➕ Add your own

Drop `MyLoader.jsx` + `MyLoader.css` into `src/loaders/` and it shows up in the gallery automatically. PRs welcome!
